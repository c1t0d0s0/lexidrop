## 🌟 概要

`Lexidrop`（レキシドロップ）は、ポップで洗練されたデザインと本格的なWeb音響・音声機能を備えた、ブラウザで遊べる英単語タイピングゲームです。

上部から少しずつ落ちてくる英単語ブロックをキーボードで正確にタイピングして消去していきます。単語を消去した瞬間、**本場アメリカ英語（en-US）のネイティブ音声で読み上げ**が行われるとともに、**対応する日本語訳がポップアップ表示**されるため、タイピングの爽快感と英語学習効果を同時に体験できます。

---

## 🎯 主な特徴と魅力

### 1. 集中できる「単体ブロック落下システム」🧩
- 画面上に落ちてくるアクティブなブロックは**常時1つ**に限定。
- どの英単語を打ち込むべきかが明確で、混乱せずにタイピングに集中できます。
- 単語の長さ（3〜4文字、5〜6文字、7〜8文字、9文字以上/2単語フレーズ）に応じてブロックの横幅とカラーが鮮やかに変化します。

### 2. 🗣️ 正解時ネイティブ英語音声発音 (Web Speech API)
- 単語を正確に入力して消去した瞬間、**Web Speech API (`SpeechSynthesis`)** により、その英単語を本場アメリカ英語のネイティブボイスでクリアに発音・音読します。
- 外部音声ファイルの読み込み待ち時間や遅延がなく、耳で英語の発音を聞きながらタイピング練習が可能です。

### 3. 🈁 日本語訳表示ポップアップエフェクト
- 正解時、ブロック自体が黒×ゴールドの高コントラストカード（例: `💡 復興・再構築`）に変化。
- 1.1秒間の表示タイムを設けることで、タイピングした英単語のスペルと日本語の意味を楽しみながらしっかり確認できます。
- 画面右端や左端で消去した際も、画面外へのはみ出しを防止する動的自動クランプ機能を搭載しています。

### 4. ⌨️ Web Audio API による音響効果
- **打鍵音**: タイプライター風の心地よいリアルタイムリアル打鍵音。
- **タイプミス判定（警告音）**: 誤ったキーを押すと「ブー」という低音ブザー音が鳴り、ブロックが振動（シェイク）。単語の最初（1文字目）からの打ち直しが強制されます。

### 5. ⚡ ピンチ時自動スローダウン ＆ 💣 3コンボ爆破ボーナス
- **ピンチ保護**: 積み上がったブロックが天井のデンジャーライン（Danger Line）に接近（140px以内）すると、落下スピードが自動的に**50%スローダウン**！Danger Lineがネオン赤に明滅し逆転のチャンスを与えます。
- **コンボ爆破ボーナス**: ノーミスで3コンボ達成するごとに、重爆発音とともに**一番上に積まれているブロックを爆破破壊** (`💣 BOMB BONUS`)！積み上がった高さを引き下げることができます。

### 6. 📖 全3,319単語の大容量データベース (カバー率100%)
- 小・中・高校必須および応用レベルまでの英単語（3,300語以上）と、使いやすい2単語熟語フレーズ（`good morning`, `thank you` 等）を網羅。
- 全3,319語の日本語訳マッピングが **100%完全網羅（未登録 0件）** されています。

### 7. ⏸️ 一時停止（ESCキー）＆ 極めてゆるやかな速度上昇
- ゲーム中、いつでも **`ESC` キー** またはヘッダーの **一時停止ボタン（⏸️）** で安全にポーズ可能。（タイピング中の「P」の誤爆を防ぐため `ESC` キー専用に保護）
- 初期速度を `0.85px/frame`、レベルアップ条件を `300点ごと (+0.05px/frame)` に設定し、大人がタイピングに集中できる落ち着いた難易度曲線へと調整されています。

## 🚀 起動方法・遊ぶ手順

### 1. ブラウザで直接開く場合
1. `lexidrop` フォルダ内の [`index.html`](file:///home/jin/work/Google/gemini-cli/lexidrop/index.html) をお使いのWebブラウザ（Google Chrome, Microsoft Edge, Safari, Firefox 等）にドラッグ＆ドロップまたはダブルクリックして開きます。
2. 「ゲームスタート」ボタンをクリックしてプレイを開始します。

### 2. ローカルサーバーで実行する場合 (推奨)
ターミナルで `lexidrop` フォルダに移動し、以下のコマンドを実行します。

```bash
# Python 3 の場合
python3 -m http.server 8000

# Node.js (npx) の場合
npx http-server -p 8000
```

ブラウザで `http://localhost:8000` にアクセスしてプレイできます。

## 🎮 操作方法

| 操作 | キー / アクション |
| :--- | :--- |
| **英単語タイピング** | キーボード（A-Z, スペースキー） |
| **一時停止 / 再開** | `ESC` キー または ヘッダーの一時停止ボタン (`⏸️`) |
| **効果音 ON / OFF** | ヘッダーのスピーカーボタン (`🔊` / `🔇`) |
| **リトライ** | ゲームオーバー画面の「もう一度プレイする」ボタン |

## 🛠️ 使用技術

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **デザインシステム**: Vanilla CSS, Google Fonts (`Fredoka`, `Zen Maru Gothic`, `Quicksand`), Glassmorphism, CSS Keyframe Animations
- **音声・音響処理**: 
  - **Web Speech API** (`window.speechSynthesis`) - 英語ネイティブ発音読み上げ
  - **Web Audio API** (`AudioContext`, `OscillatorNode`) - タイプ音、ミスブザー音、爆発音リアルタイム音響合成
- **データ管理**: JSON (`words.json`), HTML5 `localStorage` (ハイスコア保存)
